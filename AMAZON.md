**Amazon Sales Analysis Dashboard**



\## Project Overview

This project analyzes Amazon sales data using Python and Power BI.



\## Tools Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Power BI



\## KPIs

\- Total Revenue

\- Total Orders

\- Total Quantity

\- Average Order Value (AOV)



\## Dashboard Features

\- Monthly Revenue Trend

\- Revenue by Category

\- Size Distribution

\- Fulfillment Analysis

\- Order Status Analysis

\- State-wise Revenue Analysis



\## Key Insights

\- Maharashtra generated the highest revenue.

\- T-Shirt category contributed the highest sales.

\- Amazon fulfillment accounted for the majority of revenue.

\- Cancellation rate should be reduced.
